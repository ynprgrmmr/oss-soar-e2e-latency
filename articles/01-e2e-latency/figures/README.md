# Figures — 作成方針

すべて `experiments/01-e2e-latency/scripts/plot_results.py`（標準ライブラリのみ）で `raw/*/trial.json` から再生成する。
手で編集しない。数値の正はいつも `results/` の表。

## デザインのルール（dataviz の手順に沿う）

- 色: カテゴリ色を決まった順で使う（slot 1 青 → 2 橙 → 3 アクア → 4 黄 → 5 マゼンタ）。図ごとに凡例を置き、同じ図の中では対応を固定する（fig2・fig4 の条件色は共通）
- 色の検証: `validate_palette.js` で明るい背景・暗い背景とも合格（隣り合う色の色覚多様性 ΔE ≥ 8.4、通常視 ΔE ≥ 19.3）。
  明るい背景では slot 3〜5 のコントラストが 3:1 未満なので、**全系列に直接ラベル**を付け、記事には数値の表を必ず併記する
- 暗い背景: SVG 内の CSS（`prefers-color-scheme`）で暗い背景用の色に切り替える（同じ色相の別の段階を使う）
- 線は 2 px、塗りの間に 2 px のすき間、目盛り線は控えめな色、文字の色は系列色ではなく文字用の色
- 軸は 1 本だけ（2 軸グラフは作らない）
- 各要素に `<title>` を付け、ブラウザでマウスを重ねると値が出る
